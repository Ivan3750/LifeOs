# Автозбір на Raspberry Pi

Pi 5 працює тихим помічником: раз на 30 хвилин збирає дані й відправляє їх на сайт. Сайт лишається там, де є (Vercel + Aiven), Pi тільки носить дані. Нічого вводити руками не треба, а повторна відправка нічого не дублює.

## Що збирається

| Джерело | Що потрапляє на сайт |
|---|---|
| **ActivityWatch** | час на YouTube, Instagram, TikTok, Telegram та інших → розділ «Соцмережі». Ліміти й поради про скрол працюють самі |
| **Папка inbox, CSV з банку** | витрати й доходи → «Гроші» (категорія вгадується за текстом, дублі відсікаються) |
| **Папка inbox, JSON** | сон, кроки, рух, вагу, воду → «Здоровʼя» (з шорткату на телефоні або Health Auto Export) |

Те, що ти вніс руками, ніколи не перезаписується: сон і вага заповнюються лише там, де порожньо, а кроки, рух і вода тільки зростають.

## Налаштування

1. **На сервері** (Vercel або де працює сайт) додай змінну `INGEST_TOKEN`: довгий випадковий рядок, `openssl rand -hex 24`. Без неї автозбір вимкнений.
2. **На Pi:**

```bash
sudo apt install -y nodejs   # потрібен Node 20+
git clone https://github.com/Ivan3750/LifeOs.git ~/LifeOs
cd ~/LifeOs/pi
cp config.example.json config.json
nano config.json
```

У `config.json` вкажи адресу сайту (`site`), той самий `token`, увімкни потрібні джерела.

3. **Перевір вручну:**

```bash
node ~/LifeOs/pi/collector.mjs
```

Має написати, скільки записів надіслано. На сайті в «Порадах» зʼявиться рядок «Автозбір: останні дані прийшли…».

4. **Запусти за таймером:**

```bash
sudo cp ~/LifeOs/pi/lifeos-collector.service ~/LifeOs/pi/lifeos-collector.timer /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now lifeos-collector.timer
journalctl -u lifeos-collector -n 20   # журнал останніх запусків
```

Якщо твій користувач не `pi` або репозиторій в іншому місці, зміни `User=` і шлях у `lifeos-collector.service`.

## ActivityWatch

ActivityWatch ставиться на комп’ютер, де ти працюєш (https://activitywatch.net), і веде облік вікон та сайтів. У `config.json` вкажи його адресу в домашній мережі, наприклад `http://192.168.1.50:5600`. Pi має бачити цей комп’ютер у мережі, а комп’ютер має бути ввімкнений, коли збирач опитує. Сайти й застосунки, яких нема в списку за замовчуванням, додаються в `activitywatch.platforms` (назва → регулярні вирази).

## Банк (CSV)

Експортуй виписку з банку в CSV і поклади файл у папку `inbox.dir`. Назви колонок вкажи в `inbox.bank` (`date`, `amount`, `text`). Витрати мають бути від’ємними числами. Оброблений файл переїздить у `inbox/done`, а якщо сайт відповів помилкою, лишається на місці до наступного запуску.

## Формат JSON для здоровʼя

Файл `.json` в inbox: масив або `{ "items": [...] }`. Кожен елемент має `type`:

```json
{ "type": "health", "date": "2026-11-07", "sleep": 7.5, "bed": "23:30", "wake": "07:00", "steps": 9000, "workout": 30, "weight": 78.4, "water": 6 }
{ "type": "social", "ext": "phone:2026-11-07:Instagram", "date": "2026-11-07", "platform": "Instagram", "min": 42 }
{ "type": "tx", "ext": "my-id-1", "dir": "out", "amt": 59.5, "date": "2026-11-07", "note": "Netto" }
{ "type": "activity", "ext": "wolt-1", "kind": "Wolt", "start": 1783400000000, "end": 1783410000000 }
```

`ext` — стабільний ідентифікатор запису: повторна відправка з тим самим `ext` оновить запис, а не додасть другий. У `health` усі поля, крім `date`, необов’язкові.

## Безпека

- `INGEST_TOKEN` дає змогу лише додавати дані, а не читати їх. Він окремий від пароля входу, тож його можна змінити, не виходячи з сайту.
- `pi/config.json` не потрапляє в git.
- Сайт приймає до 500 записів за запит і перевіряє кожне поле.
